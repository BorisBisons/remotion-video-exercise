# YouTube Script Illustrations — "King of Leaves"

## Goal
Four illustrated panels for every timestamp beat in the 0:01–4:20 wedding-sting
script, in a single consistent ink-and-colour fashion-illustration style.

## Plan
- [ ] 1. Lock a character + style anchor sheet (Muhire, Gasuka, Papa)
- [ ] 2. Break the script into timed beats and assign the mandated camera angle
- [ ] 3. Generate 4 panels per beat, anchored to the sheet (2k, 16:9)
- [ ] 4. Index every panel in `storyboard/storyboard.md` and commit

## Emotion → angle rule (fixed)
| Emotion | Angle |
|---|---|
| Power | Low angle |
| Weakness | High angle |
| Tension | Dutch angle |
| Awe | Worm's-eye |
| Isolation | Bird's-eye or wide |
| Intimacy | Close-up |
| Conflict | Over-the-shoulder |
| Neutral | Eye-level |

Within a beat the angle never changes; only shot size progresses, so the four
panels cut together smoothly.
