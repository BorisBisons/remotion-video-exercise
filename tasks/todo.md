# YouTube Script Illustrations — "King of Leaves"

## Goal
Four illustrated panels for every timestamp beat in the 0:01–4:20 wedding-sting
script, in a single consistent ink-and-colour fashion-illustration style.

## Plan
- [x] 1. Lock a character + style anchor sheet (Muhire, Gasuka, Papa)
- [x] 2. Break the script into timed beats and assign the mandated camera angle
- [x] 3. Generate 4 panels per beat, anchored to the sheet (2k, 16:9)
- [x] 4. Index every panel in `storyboard/storyboard.md` and commit

## Emotion → angle rule (fixed)
| Emotion | Angle |
|---|---|
| Power | Low angle |
| Weakness | High angle |
| Tension | Dutch angle |
| Awe | Worm's-eye |
| Isolation | Bird's-eye or wide |
| Intimacy | Close-up |
| Conflict | Over-the-shoulder |
| Neutral | Eye-level |

Within a beat the angle never changes; only shot size progresses, so the four
panels cut together smoothly.

## Review

**What was built.** The script from 0:01 to 4:20 was broken into 27 beats and
illustrated with 108 panels, four per beat.

**Consistency approach.** One character anchor sheet was generated first,
fixing the three characters, their outfits, the gold jewellery, the warm
upper-left key light and the plain cream background. Every one of the 108
panels was then generated with that sheet as an image reference, so nothing
drifts between panels.

**Angle discipline.** The camera angle inside a beat never changes; it is set
by the beat's emotion using the table above. Only the shot size moves, from
wide to medium to close, so the four panels of a beat cut together smoothly
rather than jumping.

**Characters.** Muhire, Gasuka and Papa are original designs written from the
script. No existing artist's characters were referenced or reproduced, and
every prompt excludes text, logos, signatures and watermarks.

**Verification.** All 108 jobs completed, none failed. Two panels stalled well
past the others and were regenerated from the same anchor and prompt. The
index was rebuilt and checked: 109 images embedded (108 panels plus the
anchor sheet), zero placeholders remaining.

**Animation note.** Characters are drawn still. Animate only blinks, hair
drift, fabric sway and small hand gestures, as specified.
